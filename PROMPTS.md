# Промпты для Claude Code — Tower Defense, этап 2

Как пользоваться:
1. Положи `CLAUDE_CODE_INSTRUCTIONS.md` в корень Unity-проекта рядом с `CLAUDE.md`.
2. Открой Unity (MCP должен быть подключён), запусти Claude Code в папке проекта.
3. Перед каждым промптом — **коммит в GitKraken**.
4. Отправляй промпты по порядку. Один промпт = одна задача. Новую задачу лучше начинать в новой сессии (`/clear`), чтобы контекст не переполнялся.
5. После задачи сам запускай Play Mode и пиши Claude Code, что видишь.

```
Прочитай CLAUDE.md и CLAUDE_CODE_INSTRUCTIONS.md.
Выполни «Задачу 0 — Аудит проекта». Используй чтение файлов и Unity MCP (сцена, префабы, настройки импорта спрайтов, конфиги, manifest.json).
Код и ассеты НЕ меняй.
В конце дай таблицу: Готово / Частично / Нет / Расхождение с описанием — по каждому пункту раздела 1.
Отдельно: реальные размеры спрайтов башен и врагов (пиксели, видимая часть, PPU) и почему башни выглядят меньше врагов.
Предложи правки к плану, если что-то в проекте устроено не так, как описано.
```

После ответа:

```
Впиши итоги аудита в раздел «Текущий статус» в CLAUDE.md коротко, списком. Больше ничего не меняй.
```

## Полезные промпты на любой случай

**Ошибка в Console:**
```
В Console ошибка: [вставь текст ошибки целиком, со стеком]. Что я делал перед этим: [...]. Найди причину через MCP и код, исправь и объясни, что было не так.
```

**Что-то выглядит не так в игре:**
```
В Play Mode [опиши, что видишь]. Ожидал [что должно быть]. Проверь через MCP сцену/префаб/импорт и предложи исправление. Сначала диагноз, потом правки.
```

**Объяснить изменения:**
```
Объясни по файлам, что ты изменил в этой задаче и зачем. Для каждого файла: было → стало → почему. Простым языком.
```

**Сверка статуса между сессиями:**
```
Прочитай CLAUDE.md и CLAUDE_CODE_INSTRUCTIONS.md, посмотри git log за последние коммиты и скажи, на какой задаче мы остановились и что в ней осталось.
```

**Откат:**
```
Последние изменения всё сломали. Покажи git diff с последнего коммита и скажи, какие файлы лучше откатить. Ничего не откатывай сам.
```
